# Backend

Каталог серверного приложения «Список задач».

Стек: Java, Spring Boot / Spring MVC, Spring Data JPA / Hibernate, PostgreSQL, Flyway, Spring Security.

Вход через Google (OpenID Connect) или email + пароль. Задачи доступны только владельцу; браузер использует серверную сессию и CSRF-токен.
